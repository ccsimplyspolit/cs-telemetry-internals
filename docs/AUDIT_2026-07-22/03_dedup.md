# Cross-Project Duplicate Detection & Shared-Library Candidates

**Метод**: ripgrep pattern-based clustering + read-through spot-check
**Скоуп**: `source/drivers/`, `source/dlls/`, `source/tools/`, `source/apps/`

---

## 1. Kernel-side (drivers) — уже есть `source/drivers/shared/`

**Существует**: source/drivers/shared/stealth_mode.h — 118 LOC, `Stealth::` namespace для loader-trace cleanup + `MmUnloadedDrivers` list scrub.

**Проблема**: header-only, никем **не include**'ится в реальных драйверах (только в README). Wire-up или delete.

### Recommended `source/drivers/common/` (extract 5 modules)

| Module | Purpose | Where duplicated | Est. LOC saved |
|---|---|---|---|
| `xmem.h` | `MmCopyVirtualMemory` + SEH wrapping | 5 drivers × ~30 LOC | ~120 |
| `ptr_guards.h` | `IsKmValidVA` / `IsUmValidVA` unified | 4 drivers × 15 LOC | ~50 |
| `peb_types.h` | `LDR_DATA_TABLE_ENTRY_S` / `PEB_LDR_DATA_S` / `PEB_S` | 3 drivers × 40 LOC | ~90 |
| `poll_worker.h` | `KeInitializeEvent` + `PsCreateSystemThread` + tick loop | 4 drivers × 60 LOC | ~180 |
| `security_desc.h` | `BuildAdminOnlySd` (Admin+SYSTEM DACL) | 3 drivers × 50 LOC | ~120 |
| `log.h` | `LOG_INFO/WARN/ERROR` через `DbgPrintEx` | 5 drivers × 10 LOC | ~40 |
| `safe_lookup.h` | `SafePsLookup` + exit-status check | 5 drivers × 10 LOC | ~40 |
| `pool_tags.h` | 4CC constants unified | trivial | — |
| `device_setup.h` | `IoCreateDevice + Symlink + BUFFERED_IO` boilerplate | 4 drivers × 25 LOC | ~80 |

**Total savings**: ~**720 LOC** across kernel-mode. Plus **single point** для bug fixes, IRQL fixes, exit-status checks.

**Implementation plan**:
1. Create `source/drivers/common/` — header-only initially (matches existing `shared/` style).
2. Migrate one driver first — HexSyncCompat (smallest at 453 LOC → est. ~350 after migration).
3. Verify behavior parity (IOCTL round-trip test).
4. Roll out to остальные 4.
5. Deprecate `shared/stealth_mode.h` in favor of `common/stealth.h`.

## 2. User-mode DLLs — dedup opportunities

### 2.1 `sig_scan.h/.cpp` — 3+ копии

**Files**:
- source/dlls/AA_PeekOverride/src/sig_scan.h/cpp — 90 LOC total
- source/dlls/CS2RankSpoofDll/src/sig_scan.h/cpp — 90 LOC (bit-for-bit близко)
- source/dlls/VacLiveBypass/src/core/signature_scanner.h/.cpp — VLB variant
- source/dlls/Server-Crasher-POC-AUDIT/poc/vuln3_viewspoof/ — inline in poc

**Fix**: `source/common/sig_scan/` (header-only), used by all payload DLLs.

**Savings**: ~250 LOC.

### 2.2 MinHook подключение — 4× дубль в CMakeLists

**Files affected**:
- `source/dlls/AA_PeekOverride/CMakeLists.txt` — `MH_ROOT = "../Server-Crasher-POC-AUDIT/poc/minhook_src"`
- `source/dlls/CS2RankSpoofDll/CMakeLists.txt` — same
- `source/dlls/VacLiveBypass/CMakeLists.txt` — likely same
- `source/dlls/Server-Crasher-POC-AUDIT/poc/vuln3_viewspoof/build.bat` — direct cl

**Fix**: `source/common/minhook_cmake/CMakeLists.txt` — `add_library(minhook_static STATIC ...)` — targets `link_libraries(minhook_static)`.

**Savings**: build system consistency, ~10 min saved per new payload DLL.

### 2.3 `Vec3` / `QAngle` / basic math — 2+ копии

**Files**:
- source/dlls/AA_PeekOverride/src/sdk.h:26-46
- Server-Crasher POC likely has own
- VLB has own (view_angle_spoofer.cpp)

**Fix**: `source/common/cs2_math/vec3.h` — small `struct Vec3 { float x,y,z; ... };`, `struct QAngle {...};`

**Savings**: ~30 LOC, plus consistency.

### 2.4 CS2 schema/offsets constants — several dupes

**Duplication of RVA values**:
- `dwLocalPlayerController = 0x237FB70` appears in:
  - AA_PeekOverride/src/sdk.h:259
  - VLB/src/core/remote_offsets.h:23
  - CS2NoclipDriver/main.cpp:196
  - CS2KillTriggerDriver/main.cpp:55
  - CS2RankSpooferDriver/main.cpp:124
  - build/kit_rankspoof/Launch.ps1:134
- `dwGameRules = 0x23A49D8`:
  - VLB/src/core/remote_offsets.h:26
  - CS2RankSpooferDriver/main.cpp:125
  - CS2IsValveDSSpooferDriver/main.cpp:44

**Fix**: `source/common/cs2_schema.h` — generated from `cs2 schema/offsets/latest/offsets.json`:
```cpp
namespace cs2_schema {
    namespace client_dll {
        constexpr uint32_t dwLocalPlayerController = 0x237FB70;
        // ... auto-generated by pre-build script
    }
}
```

**Regeneration**: pre-build hook via `scripts/gen-schema-header.py`.

**Savings**: **single truth source**, prevents drift across 6+ files.

## 4. PowerShell / Batch — massive dupe

### 4.1 SCM helpers — copy-paste × 6 kits

Функции повторяются в каждом kit:
- `Get-ServiceState`
- `Wait-ServiceStopped`
- `Wait-ServiceRemoved`
- `Remove-DriverService`
- `Test-DevicePresent`
- `Start-DriverService`

**Where**:
- `build/kit_vlb_default/Launch.ps1`
- `build/kit_vlb_attack_gated/Launch-V1.ps1` (implied)
- `build/kit_aa_peek_kernel/Launch.ps1`
- `build/kit_rankspoof/Launch.ps1`
- `build/kit_isvalveds/Launch.ps1`
- `build/kit_rankspoof_dll/Launch.ps1` (created today, copied)
- `build/kit_server_crasher_poc/Launch.ps1`

**Fix**: `scripts/kit-common/Scm-Helpers.ps1` — dot-source at top of each kit Launch:
```powershell
. "$PSScriptRoot\..\..\scripts\kit-common\Scm-Helpers.ps1"
```

But: kit's are meant to be **standalone** (self-contained для redistribution). Compromise: at build time, `sync-kit.ps1` копирует helper module в kit. Kit user's don't need repo layout.

**Savings**: ~500 LOC of PS across kits.

### 4.2 KDU driver blocklist off + Afterburner kill + HVCI probe

Каждый kit имеет одинаковый Setup-KduPrereqs block:
```powershell
foreach ($p in @('MSIAfterburner', 'RTSS', ...)) { ... }
Start-Sleep -Milliseconds 500
if ([Environment]::OSVersion.Version.Build -ge 22621) {
    $ci = "HKLM:\System\CurrentControlSet\Control\CI\Config"
    Set-ItemProperty ...
}
# HVCI probe
$dg = Get-CimInstance ...
if ($dg -and $dg.SecurityServicesRunning -contains 2) { Die ... }
# KDU chain
$chain = @([int]$KduProvider) + $FallbackChain | Select-Object -Unique
foreach ($p in $chain) { Invoke-Dse ... }
```

**Fix**: `scripts/kit-common/Setup-KduPrereqs.ps1` → single `Invoke-KduPrereqs -Provider $KduProvider -FallbackChain @(1,2,4,5,14)`.

**Savings**: **~2000+ LOC of PS** duplicate.

### 4.3 UAC wrapper `.bat`

Все kit Launch.bat идентичны с точностью до имени `Launch.ps1`:
```bat
@echo off
setlocal
cd /d "%~dp0"
powershell -NoProfile -ExecutionPolicy Bypass -Command "Start-Process powershell -ArgumentList '-NoProfile','-ExecutionPolicy','Bypass','-File','\"%~dp0Launch.ps1\"','%*' -Verb RunAs -Wait"
exit /b %ERRORLEVEL%
```

**Fix**: `scripts/kit-common/uac-wrapper.template.bat` — copied by kit generator.
